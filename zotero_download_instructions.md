### Step 2: Connect to UMich Network

### Step 3: Batch PDF Retrieval
1. Click on the **"Bulk Download Queue (2016-2026)"** collection
2. Select all items: **Ctrl+A** (or Cmd+A on Mac)
3. Right-click → **Find Available PDFs**
4. Zotero will work through the list, downloading PDFs via your institutional access
5. This will take **several hours** for 12,500+ items — let it run in the background
6. Not every PDF will be found (expect ~50-70% success rate)

### Step 4: Check Results
After the batch completes:
- Items with a PDF icon got downloaded successfully
- Items without one either aren't available through your institutional access or Zotero couldn't find them

### Tips
- **Do this in batches** if Zotero stalls on large selections. Try 1,000–2,000 at a time instead of all at once.
- **Run it multiple times.** Zotero skips items that already have PDFs, so re-running is safe and may catch ones it missed.
- **Check Zotero storage settings.** Make sure you have enough local disk space. At ~1-5MB per PDF, 12,500 papers could be 12–60GB.
- **Zotero sync vs. local storage.** If you have Zotero cloud sync, be aware of storage limits (300MB free). For bulk downloads, you may want to store PDFs locally only, or use ZotFile/Zotero's linked file attachment mode.

### Step 5: Revoke the API Key (After You're Done)
The API key used for this process has full read/write access to your library. Once you're satisfied with the results, go to [zotero.org/settings/keys](https://www.zotero.org/settings/keys) and either delete or regenerate this key.
